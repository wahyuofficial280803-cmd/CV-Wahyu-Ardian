## 🚀 Cara Upload ke GitHub & Online di Vercel

### Langkah 1: Push ke GitHub
Di folder ini sudah disediakan file otomatis **`push-ke-github.bat`**:
1. Buka folder kerja di File Explorer.
2. Klik 2x file **`push-ke-github.bat`**.
3. Jika muncul jendela login GitHub di browser, klik **Authorize / Sign in with your browser**.
4. Semua file akan otomatis terunggah ke: `https://github.com/wahyuofficial280803-cmd/CV-Wahyu-Ardian`.

### Langkah 2: Deploy di Vercel (Gratis & Cepat)
1. Buka [vercel.com](https://vercel.com) dan login dengan akun GitHub Anda.
2. Klik tombol **"Add New..."** lalu pilih **"Project"**.
3. Pilih repository **`CV-Wahyu-Ardian`**, lalu klik **"Import"**.
4. Biarkan konfigurasi default (Framework Preset: *Other*).
5. Klik **"Deploy"**.
6. Dalam hitungan detik, website CV & Portofolio Wahyu Ardian sudah online dengan domain aktif! 🎉
