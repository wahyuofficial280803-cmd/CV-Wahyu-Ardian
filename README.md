# CV & Website Portofolio - Wahyu Ardian

Selamat datang di website CV & Portofolio resmi untuk **Wahyu Ardian**.

## 🚀 Fitur Website
- **Modern & Responsive Design**: Tampilan estetik dengan dukungan Dark Mode & Light Mode.
- **Tombol WhatsApp & Email Langsung**: Menghubungi Wahyu dengan satu klik ke nomor `083832412105` dan email `Wahyuofficial280803@gmail.com`.
- **Fitur Cetak / Simpan ke PDF**: Tombol "Cetak / Simpan CV PDF" yang sudah dioptimalkan khusus untuk cetak kertas A4 standar HRD/perusahaan.
- **Galeri Portofolio Interaktif**: Filter kategori Desain Grafis, Fotografi Acara, dan Visual Editing lengkap dengan modal pratinjau (lightbox).
- **Fitur Scan QR Code Interaktif**: Kotak pemindai QR Code dengan animasi laser scanner dan tombol perbesar/unduh agar audiens atau rekruter bisa langsung scan portofolio Anda menggunakan smartphone.
- **Sosial Media Lengkap**: Link aktif ke Instagram, TikTok, dan Facebook.
- **Riwayat Pengalaman & Pendidikan Terstruktur**: Timeline karir (CMB Media, Family Printing, PGRI Porsenijar, Wisuda UNILAK) dan riwayat pendidikan lengkap.

## 📁 Struktur Berkas

## 📸 Cara Memasang Foto Profil Anda Sendiri
1. Siapkan foto terbaik Anda.
2. Beri nama berkas foto: `profile.jpg` (atau `.png`).
3. Masukkan ke dalam folder `assets/images/`.
4. Jika menggunakan nama lain, cukup buka `index.html` dan ganti bagian `src="assets/images/profile-placeholder.svg"` menjadi nama file foto Anda.

## 🌐 Cara Menjalankan
1. Buka folder ini di File Explorer.
2. Klik 2x file `index.html` untuk membuka langsung di Google Chrome, Microsoft Edge, atau browser pilihan Anda.
3. Anda juga bisa langsung mengunggah folder ini ke **GitHub Pages**, **Vercel**, atau **Netlify** secara gratis untuk mendapatkan link website online Anda sendiri!
